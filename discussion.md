# Ответы на твои вопросы:

1. **RAG корпус:** бери доменный корпус с закрытым тестом. Лучший вариант — набор документов по теме статьи (научные абстракты о MAS/LLM, 30–50 текстов) + 20–30 вопросов, ответы на которые *полностью* лежат в корпусе. Тогда `answer accuracy` измерима объективно (совпадение с эталоном), а не только субъективно. Второй вариант — публичный бенчмарк (например, подмножество MMLU/GPQA с документами), но там легче утечка ответов в веса 9b — у тебя это и есть научный вопрос, так что корпус с закрытым тестом чище.
2. **Метрики/статистика:**
   - Отдельная метрика *объективная* — по эталонным ответам (exact match / F1 по словам), не только Likert.
   - `--runs ≥ 3` для consistency; в статистику бери среднее по повторам на задачу (парные наблюдения).
   - Дополнить Wilcoxon: эффект-размер (Cliff's delta) и плюс-минус w/ties по задачам — «в скольких задачах MAS выиграл/проиграл».
   - При >1 эксперте-оценщике — Krippendorff's alpha (межэкспертная согласованность).
   - Фиксируй **стоимость**: MAS тратит ~4× токенов (видно на тесте: 2547 vs 174) — выводы должны обсуждать trade-off качество/стоимость.
